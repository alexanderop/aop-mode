## Same task. Three real agents.

The initial suite checks a pagination repair, a read-only access-control review,
and an ordinary file edit that must leave aop-mode inactive. Run one case while
developing, or run the full matrix before a release.

```sh
pnpm test:harnesses --harness codex --task repair
pnpm test:harnesses
```

Compatibility is a claim about a **specific task and version**. Read the
[latest local evidence](/evidence/latest/) before assuming a workflow is covered.
