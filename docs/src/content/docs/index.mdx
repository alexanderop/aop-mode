aop-mode adds explicitly invoked coding workflows to Claude Code, Codex, and
Copilot CLI. Use it to investigate a bug, review a change, or implement a feature
with verification steps.

The original workflow ideas, skills, and playbooks come from
[pstack](https://github.com/cursor/plugins/tree/main/pstack), created by
[Lauren Tan (poteto)](https://github.com/poteto). aop-mode packages and adapts that
work for other coding agents. [Credits and source](/aop-mode/credits/).

Install the skills in a project, then name the workflow in your request. For example,
in Codex:

```text
$aop-mode Fix the first page skipping items. Reproduce the bug before
editing, preserve the public API, and show the failing and passing checks.
```

In Claude Code and interactive Copilot CLI, use `/aop-mode` instead.
[Installation](/aop-mode/getting-started/) covers discovery and invocation differences.

## Start with a small task

[Install aop-mode](/aop-mode/getting-started/) in one project, then
[fix your first bug](/aop-mode/first-workflow/). The walkthrough follows a pagination
error from reproduction to verification, with a concrete expected result.

For the mechanism behind the command, read [how aop-mode works](/aop-mode/workflow/).
If you already know which workflow you need, choose one from the
[skill catalog](/aop-mode/catalog/), such as `tdd`, `how`, or `interrogate`.

## Check what has been tested

The evaluation suite runs coding agents in disposable task workspaces and checks
the files and behavior they leave behind. It covers a pagination repair, an
access-control review, and an ordinary edit that should leave aop-mode inactive.

[Inspect the evidence](/aop-mode/evidence/latest/) for recorded CLI versions and
outcomes. A passing task establishes that result for that run; other workflows
and runtime capabilities need their own checks.

## Where the workflows come from

aop-mode is an independent project built on
[Lauren Tan's pstack](https://github.com/cursor/plugins/tree/main/pstack). It bundles
the pinned original skills, adds personal principles, and adapts invocation and
tools to each supported coding agent. [Read the credits](/aop-mode/credits/).
